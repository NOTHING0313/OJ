# 赛季成绩权限与个人历史成绩 — 2026-09-05

## 已完成与实现复用

| 范围 | 修改 | 复用与边界 |
|---|---|---|
| 后端赛季查询 | 全量当前榜、单题榜、历史榜收口到 Root；新增 Root 按用户查当前/历史成绩 | 复用 `LeaderboardSeasonService`；个人和 Root 走相同私有投影逻辑 |
| 答题者历史 | 修复历史接口控制器/服务角色冲突，恢复个人入口，显示归档与逐题成绩 | 复用原 `GetPersonalHistoryAsync`、归档实体和 DTO |
| Root 查询 | 榜单用户名可进入个人成绩；用户管理提供“赛季成绩”，可结合既有搜索定位用户 | 复用管理页、用户查询与个人成绩组件，无平行管理系统 |
| 路由和调用方 | Root 专属榜单路由；普通用户首页不请求全量成绩；题目页仅 Root 请求单题榜 | 后端仍独立校验，前端不是权限依据 |
| 身份展示 | 个人结果 DTO 增加用户 ID、用户名，空状态也展示被查用户 | 无数据库迁移 |

原有计分、赛季生命周期、排名快照和归档数据没有重写。出题者读取不含个人成绩的赛季配置仍被保留，以维持挑战编辑的赛季关联。挑战榜单及旧挑战聚合榜不在这次调整范围。

源码范围：三个赛季控制器、原服务接口与服务、个人 DTO、相关前端 API/路由/榜单/个人/用户/题目调用方，以及赛季和权限测试。最终风险仍为经用户明确授权的 R4；无意外存储、依赖或其他授权边界变更。
